<details>
<summary>🔧 附：Get-EbookInventory.ps1 的功能</summary>

这个脚本会帮人类把书库扫一遍，整理成清单喵呜。流程大概是：

1. **以脚本所在目录为根**，递归扫描所有文件，排除 `.csv` / `.txt` / `.ps1` / `.md` / `.xlsx` 和隐藏文件，同时跳过 `output\` 目录本身。
2. **解析每个文件名**：
   - 先剥掉末尾的 `(z-library.sk, 1lib.sk, z-lib.sk)` 标记，记录是否带标记；
   - 再从末尾往前找“最外层一对括号”，把括号内容当作者、括号前当书名（要求左括号前是空格或行首）；
   - 如果作者是 `etc.` 或缺少 z-lib 标记，就在备注里标出来；实在解析不出来的，整条标记为“不符合标准格式”。
3. **输出三个文件**（都带时间戳，放在 `output\` 下）：
   - `*-readlist.md`：文件级清单，含书名、作者、格式、大小、目录、是否标准、备注；
   - `*-readlist.csv`：同上，CSV 格式；
   - `*-readlist.xlsx`：按目录分 Sheet，每个 Sheet 里按“书名+作者”聚合，用 ✔ 标出有哪些格式，附大小合计、文件数、备注；第一个 Sheet 是 `Summary`，汇总各目录的书目数、文件数、总大小、不符合标准的数量。
4. **写入前做 Sheet 名清洗**：去掉 Excel 不允许的字符、截断到 31 字符、重名自动加后缀。
5. **最后打印**：输出文件路径、Sheet 列表、总文件数、不符合标准数、`etc.` 占位数。

依赖 `ImportExcel` 模块。脚本文件建议改名为 `Get-EbookInventory.ps1`。

</details>
